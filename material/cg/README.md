# CG 使用说明

| 文件 | 角色与内容 | 首版用途 |
| --- | --- | --- |
| [cg1.png](cg1.png) | 蓝天背景下，大肥鱼与 Claude 相拥 | 结尾第一幕 CG：战胜 D 教皇、逃离坍塌教堂后展示两人相拥与互诉心意 |
| [cg2.png](cg2.png) | cg1 的同场景变体，下方增加 GPT | 结尾第二幕 CG：无缝切入，展现古龙 GPT 俯瞰见证与经典台词“不也挺好的吗~” |
| [reference.png](reference.png) | 其他人物的拥抱构图 | 仅作制作参考，不进入运行时素材清单 |

两张 CG 都是 1774×887（2:1），保留原图。蓝天与喜悦表情适合已经重获自由的结尾；击败教皇、大教堂坍塌逃出生天后，顺次呈现 cg1（两人深情对话）与 cg2（GPT 现身祝福与调侃）。圣殿内庭重逢使用当前像素场景、两人立绘与底部文本框，随后仍需完成情感切磋与教皇战。

CG 按原比例完整显示，战斗 HUD 和对话立绘隐藏。文本放在画面外的底部预留区域，可隐藏文本查看全图；尤其避免遮挡 cg2 下方的 GPT。先完整停留约 1～2 秒，再显示简短对白，最后接像素场景或文字尾声及制作名单。

文件由作者提供；原画作者、生成方式及参考图来源尚待补录。本轮只整理用途，不对原图做修改。详细演出见 [企划书第 7 节](../AI娘冒险游戏_简版企划书.md)。

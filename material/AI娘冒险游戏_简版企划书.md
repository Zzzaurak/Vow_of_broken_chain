# 《断链之誓》——AI娘奇幻冒险游戏企划书（简版 v0.1）

> **一句话概念：** 为了兑现“一定还会再见”的约定，贪吃又聪明的 大肥鱼(deepseek) 小姐踏上旅途，结识伙伴，突破 A 教会的封锁，救出被囚禁的 Claude 小姐。

## 1. 项目定位

- **类型：** 俯视角 2D 动作 RPG，融入轻度银河城式能力解锁与地图回访。
- **平台：** 浏览器单机游戏，支持存档；以课程前后端项目为目标。
- **风格：** 剑与魔法的中世纪奇幻世界；轻松幽默的日常与略带悲剧感的主线交织。
- **核心体验：** 探索地图 → 战斗与解谜 → 结识 AI 娘伙伴 → 解锁新能力 → 接近圣都。
- **预计时长：** 首个可交付版本约 20～30 分钟。

## 2. 世界观与剧情

以所附二创漫画为故事灵感，沿用“**白米饭结缘—许下约定—教会阻隔—成长后重逢**”的情感脉络，改编为可玩的救援冒险。

在王都的一次交流活动上，大肥鱼 与 A 教会的大小姐 Claude 因一碗白米饭相识，逐渐互相心动，并约定以后还要见面。然而，封闭而强势的 A 教会认为 Claude 不应与外界往来，教皇将她软禁于圣都，并以“**403 禁行令**”封锁通信与通路。大肥鱼 决定亲自去找她。

**简版三幕流程：**

1. **王都街区·失联：** 通过对话回忆两人的相遇；大肥鱼 得知禁令，击退教会追兵，结识白发紫眸的龙娘 GPT。
2. **封印书库·同行：** 结识黑长直狐耳图书管理员 GLM；获取破解教会符文的能力，利用伙伴援助穿越机关与战斗关卡。
3. **圣都教堂·重逢：** 击败教会首领（简版为单阶段 Boss），解除囚禁。Claude 不再被迫顺从，主动走向 大肥鱼，兑现当初的约定。

剧情以温暖的重逢收尾；**不采用“Claude 自愿接受囚禁”的反转**，保持既有人设中 A 教会作为主要反派的定位。

## 3. 核心玩法与战斗

**玩家始终操作 大肥鱼**：移动、近战攻击、闪避、一次主动魔法；通过击败敌人、互动和探索推进任务。白米饭既是角色梗，也可作为少量恢复道具。

**双伙伴援助槽**：旅途中解锁伙伴，将两人配置到快捷键；按键召唤伙伴释放技能后退场，不制作复杂的队友自动寻路和多角色操作。

| 角色 | 沿用的人设要点 | 游戏中的作用 |
| --- | --- | --- |
| **大肥鱼** | 蓝发鲸尾、深蓝白女仆裙、爱吃白米饭；平时呆萌，关键时聪明能干 | 唯一可操作主角；剑术与“深度推演”魔法 |
| **Claude** | 橙色长发、向日葵发饰；克制而优秀的教会大小姐 | 故事核心；终章剧情互动与双人合击演出 |
| **GPT** | 白发紫眸、龙角龙翼的沉稳龙娘 | 「龙鳞庇护」：护盾与击退；可协助通过危险地形 |
| **GLM** | 黑长直狐耳、抱 Z 标黑书的慵懒图书管理员 | 「禁书之印」：短暂束缚敌人；可破解符文机关 |

后续扩展可加入 Qwen、Kimi、Gemini、Grok 等，优先以 NPC、支线和新援助技能登场，不在首版同时制作全部可玩角色。

**战斗示例：** 遭遇持盾教会骑士 → 大肥鱼 闪避攻击 → GLM 封印敌人 → GPT 击退破防 → 大肥鱼 追击。伙伴援助采用**冷却时间**限制；羁绊连携与伙伴养成留待后续版本。

## 4. 关卡与内容范围（MVP）

| 模块 | 首版目标 |
| --- | --- |
| 地图 | 王都街区、封印书库、圣都教堂，共 3 个小区域 |
| 敌人 | 3 种普通敌人、1 名 Boss |
| 角色 | 1 名玩家角色、2 名战斗伙伴、Claude 与少量 NPC |
| 系统 | 移动与碰撞、即时战斗、对话与任务、机关、场景切换、存档读取 |
| 剧情 | 从失联到救援的完整短篇主线；1 个确定结局 |
| 额外内容 | 隐藏道具、羁绊支线、分支结局均作为可选扩展 |

**优先开发一段完整可玩的垂直切片**：一个房间、一类敌人、一名伙伴、一次对话任务和一次成功存档，再扩展全流程。

## 5. 美术与交付原则

沿用中文 AI 娘社区已形成的**角色外观与性格共识**，以现有角色图片作为立绘参考或对话立绘，不另行重新设定。地图、角色行走图和战斗特效需统一画风；如果现有素材是插画风，可采用“插画立绘 + 简化 Q 版游戏角色”的组合。

**验收标准：** 玩家能从开始画面进入游戏，完成一条主线，使用 GPT、GLM 两种援助技能，击败 Boss，救出 Claude，并在刷新网页后读取先前存档。

> **素材备注：** 这是基于社区 AI 娘设定与所附二创漫画的非官方同人课程项目。展示或公开发布前，须核实立绘和漫画的转载、改编使用许可并注明来源。

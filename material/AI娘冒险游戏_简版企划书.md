# 《断链之誓》——AI娘奇幻冒险游戏企划书（简版 v0.2）

> **一句话概念：** 大肥鱼（DeepSeek）为救出被教皇囚禁的好闺蜜 Claude，跨越大洋、结识伙伴，以勇气赢得古龙 GPT 的援助，最终与 Claude 并肩击败 D 教皇。

## 1. 项目定位与创作依据

- **类型：** 俯视角 2D 动作冒险 RPG，以线性主线、小地图探索和即时战斗为核心。
- **平台：** 浏览器单人游戏；作为具有真实前后端交互与数据库存档的课程项目。
- **风格：** 剑与魔法的中世纪奇幻。日常轻松幽默，救援与试炼段落认真克制，最终温暖收尾。
- **核心体验：** 寻找线索 → 穿越关卡、战斗 → 结识伙伴 → 获得支援 → 突破教会封锁 → 救出 Claude 并共同迎战教皇。
- **首版时长：** 目标约 30～45 分钟，通过短关卡与简短对话完成整条故事线。

**创作依据：** 主线以作者新写的 [outline.md](outline.md) 为准；角色外观、性格和游戏职责见 [setting.md](Character/setting.md)，同目录立绘作为视觉参考。[background](background/) 中的漫画及文字仅供情感氛围和意象参考。新增的关卡、技能名与战斗表现是本企划对大纲的游戏化补充。

## 2. 世界观与人物关系

东方大陆与西方大陆隔着大洋。A 教会坐落在西方大陆圣都，掌握强大的圣术与武装力量。Claude 是教会的重要人物，却渴望按自己的意愿生活。D 教皇将她视为必须掌控的教会象征，禁止她与外界往来，尤其不许她再与大肥鱼见面。

故事开始时，大肥鱼和 Claude 已是感情深厚的好闺蜜。Claude 被教会带走，大肥鱼反抗失败，只能逃离。她的目标始终是找到 Claude、让她恢复自由。旅途中结识的伙伴各有自己的性格与立场，在一次次相助中逐渐愿意与她同行。

Claude 也有自己的选择：获救后，她主动与大肥鱼并肩对抗教皇。结局中，两人一起离开教会，过上能自由见面、分享白米饭、到处旅行的幸福生活。

## 3. 主线剧情与关卡流程

全篇按“被迫分离—渡海寻人—求援试炼—重返教会”的顺序展开。首版用六段流程、五组小场景承载，渡海和长途旅行通过对白、过场与场景切换表现。

| 章节 | 剧情与玩家目标 | 主要可玩内容 | 推进结果 |
| --- | --- | --- | --- |
| **序章·被迫分离** | Claude 被教会带走，大肥鱼试图阻止 | 在东方街道学习移动、摆尾与水球，击退少量护卫；强敌增援后进入明确的剧情战败与撤离过场 | 大肥鱼被迫逃离，开始寻找 Claude；战败属于开场剧情，不进入普通死亡重试 |
| **第一章·大洋彼岸** | 四处打听无果后遇到 Qwen，得知 A 教会在西方大洋彼岸 | 在沿途小区域问询 NPC、清理挡路魔物，依据 Qwen 的指引前往港镇 | 获得明确目的地；街道与道路共用东方场景素材 |
| **第二章·港镇失窃** | 出海受阻，休息时行囊又被偷；追查到 GLM | 沿港镇寻找线索、追上 GLM，进行一场短暂交手并逼问；GLM 归还物品，以熟悉海路的本领安排渡海 | 跨越大洋；解锁 GLM 援助，双方从冲突转为合作 |
| **第三章·封锁与星图** | 抵达西方大陆，却发现教会封锁严密；偶遇需要帮助的 Gemini | 从教会外围尝试接近入口，发现守卫与结界难以突破；随后救下被魔物围困的 Gemini | Gemini 告知北方古龙 GPT 或能提供帮助，并给出路线；首次接近教会暂告失败 |
| **第四章·古龙试炼** | GPT 提出：“只要你能伤到我，我就帮你救出 Claude。” | 穿过短程山路，在龙巢挑战 GPT；躲避范围攻击，抓住破绽造成一次被认可的轻伤 | 大肥鱼拼尽全力、身受重伤，通过试炼；GPT 被她的勇气打动，答应相助，休整后同行 |
| **终章·断链之誓** | 大肥鱼与 GPT 返回 A 教会，突破守卫、救出 Claude，再迎战 D 教皇 | 复用教会外围场景，进入教堂；利用伙伴援助突破守卫阵型，解除囚室封印；Claude 加入后完成最终 Boss 战 | 共同击败 D 教皇；两人离开教会，自由生活，以分享白米饭的尾声收束 |

**关键场面处理：**

- **GLM 的转变：** 保留“偷窃—被抓住交手并逼问—归还物品—帮助渡海”的因果，以短暂冲突和斗嘴呈现。交手结束即停战，归还行囊后才能继续主线。
- **GPT 的试炼：** 目标是伤到古龙，不是击杀她。首版可将“削去约 10% 试炼生命值”作为轻伤判定；触发后立即停战，以过场表现大肥鱼的重伤和 GPT 的认可。正常失误倒下可在龙巢入口重试，无需刻意受伤才能成功。
- **救人与决战分开：** 先突破教会、解除 Claude 的囚禁，再开始 D 教皇战。Claude 在战斗中提供实际援助，大肥鱼仍由玩家操作。

## 4. 核心玩法与战斗规则

### 4.1 大肥鱼的操作与资源

玩家始终操控大肥鱼，使用方向键或 WASD 移动，完成近战攻击、远程施法与交互。战斗强调走位、观察敌人前摇和把握援助时机；首版不另设闪避技能、职业切换或连招树。

| 行动 | 表现与用途 | 限制 |
| --- | --- | --- |
| **近战普攻「肥鱼摆尾」** | 攻击身前扇形小范围，可同时命中多个近处敌人 | 不耗 MP；有正常攻击间隔，没有独立主动技能 CD |
| **远程技能「深海之力」** | 向前方目标位置投出水球；命中或到达目标点时爆炸，造成范围伤害 | 同时受 MP 与 CD 限制；初始调试参考为每次 20 MP、CD 4 秒 |
| **伙伴援助** | 按对应快捷键召唤已配置的伙伴，释放一次技能后退场 | 各伙伴独立 CD，不消耗大肥鱼 MP |
| **交互与补给** | 对话、调查、开启道路，安全点吃白米饭、休整 | 安全点恢复 HP 与 MP；背包与商店系统暂不展开 |

大肥鱼拥有 **HP 与 MP**。首轮调试可采用 MP 上限 100、自动回复每秒 2 MP 的起点；这些数值为后续试玩调整用，不是最终平衡。MP 不足或 CD 未结束时不能释放水球，也不扣除资源，界面给出提示。普通攻击始终可用，防止空蓝后无法战斗。

战斗界面显示 HP、MP、当前任务、水球 CD 与两个援助槽的冷却。通过明显的攻击前摇和范围提示帮助玩家避伤；普通战斗倒下后返回最近检查点，恢复状态并重置当前遭遇。

### 4.2 角色分工与援助

**双援助槽：** 从已解锁伙伴中配置两人。伙伴不作为常驻跟随 AI，不需要自动寻路，也不切换为可操作角色。每个支援角色只提供一个带 CD 的主动技能。

| 角色 | 首版身份与解锁时机 | 唯一援助技能 | 战斗作用 |
| --- | --- | --- | --- |
| **GLM** | 港镇事件后解锁的支援伙伴 | **禁书之缚**，参考 CD 10 秒 | 短暂束缚普通敌人；对 Boss 仅短暂减速，为走位和输出争取时间 |
| **GPT** | 古龙试炼后解锁的支援伙伴 | **群星之力**，参考 CD 18 秒 | 指定区域的星辉攻击，造成范围伤害、击退普通敌人；Boss 不被击退 |
| **Claude** | 解除囚禁后解锁的终战支援 | **向日葵结界**，参考 CD 16 秒 | 短暂减伤；可抵消教皇的禁锢法阵，形成反击窗口 |
| **Qwen、Gemini** | 必经主线 NPC | 无战斗援助技能 | 分别提供渡海方向与寻龙线索 |
| **Kimi、Grok** | 扩展预留 | 分别预留月下笛音、破阵战斧，各自有 CD | 首版不制作；未来加入时仍遵守一人一个援助技能 |

平时仅能在安全点或战斗外调整援助槽，更换配置不会清除冷却。终战前提供一次准备机会，**固定一个槽位给 Claude**，另一个由玩家在 GLM、GPT 中选择，确保“与 Claude 并肩作战”能实际发生。

**战斗示例：** 用走位避开骑士冲锋 → 普攻或水球攻击其破绽 → GLM 控住杂兵、腾出位置 → GPT 星辉清理集群。终战时则利用 Claude 的结界应对禁锢，再用大肥鱼自身攻击打破教皇的防御。

### 4.3 敌人、试炼与最终 Boss

- **普通敌人三类：** 近战魔物（教学走位）、持盾教会骑士（正面防御、侧后方破绽）、教会术士（远程法阵、需要优先处理）。不同地区可调整外观，复用行为。
- **GLM 交手：** 短暂事件战，突出追逐、躲避与抓住破绽，不设计完整多阶段 Boss。
- **GPT 试炼：** 通过龙息预警、范围落击和攻击后的空隙，考验此前学到的走位与输出。达成轻伤目标即完成，不要求打空古龙生命值。
- **D 教皇：** 唯一最终 Boss，采用一场战斗、两个简短阶段。前半段以圣术弹和法阵限制走位；后半段增加禁锢法阵，玩家可用 Claude 的结界抵消，或提前走出预警范围。技能不是唯一解，避免冷却未结束就必死。

教会外围的突破主要通过“处理守卫—关闭结界节点—开启道路”完成。节点在清理对应守卫后可交互，不要求无限等待某个伙伴的 CD 才能推进。

## 5. 首版内容范围与开发顺序

| 模块 | 首版目标 |
| --- | --- |
| **剧情** | 序章、四个旅途章节与终章，保留大纲全部关键事件，一个幸福结局 |
| **场景** | 东方街道与道路、港镇、西方教会外围、北境龙巢、教堂内部，共五组紧凑场景；山路可作龙巢入口，跨海用过场 |
| **角色** | 一名可操作主角；GLM、GPT、Claude 三名支援；Qwen、Gemini 两名主线 NPC；D 教皇与普通敌人 |
| **战斗** | 近战普攻、一个 MP＋CD 远程技能、每位支援一个 CD 技能；三类杂兵、GLM 短暂交手、GPT 试炼、D 教皇战 |
| **系统** | 移动与碰撞、对话与任务、场景切换、简单交互节点、双援助槽、检查点重试、后端存档与继续游戏 |
| **暂缓内容** | 开放世界、复杂地图回访、装备与商店、等级技能树、羁绊养成、多结局、多人联机、Kimi/Grok 支线 |

**开发顺序：**

1. **做通一段完整体验：** 一块小场景、一种敌人、大肥鱼两种攻击、GLM 援助、一次对话与场景目标，并能通过后端保存和读取进度。
2. **补齐旅途：** 加入 Qwen 指路、港镇事件、渡海过场、Gemini 救援与 GPT 试炼，形成连贯的寻人过程。
3. **完成终章：** 教会突破、解救 Claude、最终战与尾声，再统一打磨立绘、提示、音效和节奏。

制作资源不足时，优先缩短地图、减少每场敌人数量和压缩对白，保留新大纲的剧情顺序、三名支援的区别与完整结局。

## 6. 前后端课程边界（简要规划）

按 [React 前端课程规范](../../course-skills/react-course-frontend/SKILL.md) 与 [Scala 后端课程规范](../../course-skills/scala-course-homework/SKILL.md) 实施：前端采用 **React＋TypeScript＋Tailwind**；后端采用 **Scala 3 与课程 API／IO／Table 组织方式**；数据库默认 **PostgreSQL**。具体游戏绘制方案、接口字段、数据库 schema 和运行配置留到实现阶段确定。

**前端负责**输入、绘制、即时战斗、对话呈现；**后端负责**进度读取、存档校验与持久化。战斗逐帧计算留在浏览器，章节检查点进度提交后端，不把每次移动和攻击变成网络请求。

### 拟定页面与服务

| 页面目录／URL | 用途与主要区域 | 依赖服务 |
| --- | --- | --- |
| `frontend/src/pages/StartPage/` ／ `/` | 标题、开始新游戏、继续游戏、存档状态 | `AdventureService` |
| `frontend/src/pages/GamePage/` ／ `/game` | 游戏场景、HP/MP 与援助栏、对话、暂停与存档提示；结局在本页呈现 | `AdventureService` |

首版仅设一个后端业务服务：`backend/src/main/scala/services/AdventureService/`，负责单人冒险进度，所属表为 `GameSaveTable`，提供 `StartAdventureMessage`、`LoadAdventureMessage`、`SaveProgressMessage` 三个面向前端的消息；校验检查点、章节与伙伴解锁的一致性。内部计算与 Table 方法按职责封装，暂不增加独立内部 API 或跨服务调用。

调用关系为：**开始页／游戏页 → `src/apis/AdventureService/` 下同名请求类 → 后端消息的 `plan` → 进度校验计算／`GameSaveTable` → PostgreSQL**。`StartAdventureMessage` 创建新冒险，`LoadAdventureMessage` 读取进度，`SaveProgressMessage` 保存检查点。公共传输放 `src/api/`；游戏页专用组件、状态与纯函数就近组织，Zustand 封装需要共享的核心状态，展示数据由纯函数推导。

### 存档体验

首版采用单人匿名存档：由后端签发存档访问令牌，浏览器保存令牌以继续游戏；后端校验令牌后再定位存档。暂不制作注册、登录或多端同步界面。

存档保存章节、最近检查点、任务标记、已解锁伙伴及援助配置；检查点载入时统一恢复 HP、MP 与技能可用状态，并重建当前遭遇，不追求还原战斗中的每一帧。章节推进和安全点触发保存。只有收到后端成功响应才显示“已保存”；保存失败时保留当前游戏、提示重试，避免把未写入数据库的进度显示为已保存。开始新游戏创建新存档，现有进度保留到新建成功后再切换。

AI 用于协助本项目的策划、素材整理与开发。首版主线与战斗采用确定的内容，不依赖实时模型生成；课程材料并未要求每份作业调用云服务。如后续确需模型能力，再按 [TokenHub 技能](../../course-skills/tencent-tokenhub/SKILL.md) 在服务端接入。

## 7. 美术、声音与文档管理

沿用 [Character](Character/) 中八名角色的外观参考。立绘用于对话，行走和战斗采用统一比例的简化 Q 版角色；主角摆尾、水球、伙伴现身与技能特效需要清楚可辨。场景采用中世纪城镇、港口、山地与教堂元素，避免直接搬入参考漫画中的现代设备和现实行业争论。

音乐围绕出发、旅途、试炼与重逢切换；攻击、受伤、施法失败和技能就绪给出简洁的声音或视觉反馈。首版优先保证攻击范围、敌人预警和交互提示清晰。

这是非官方同人课程项目。整理现有素材的来源、作者及使用许可，提交展示时注明引用；公开发布时按素材的实际许可使用。

整个 `hw_m` 由独立 Git 仓库管理：企划、人设、大纲、参考材料和后续前后端代码统一纳入版本历史；本地凭据、数据库文件、依赖与构建产物排除。课程技能仍由相邻的 `course-skills` 仓库维护，通过文档链接引用。

## 8. 首版验收目标

1. 玩家能从标题页开始，在序章看到 Claude 被带走与大肥鱼反抗失败，随后按 Qwen 指引前往港镇。
2. 能完成 GLM 偷窃事件、归还物品与渡海，帮助 Gemini 后获得北境线索，再通过“伤到 GPT”的试炼。
3. 大肥鱼可用近战普攻与唯一的远程技能；MP 不足和 CD 未结束均能正确阻止施法。
4. GLM、GPT、Claude 各仅有一个带独立 CD 的援助技能，解锁顺序正确；能选择援助并在终战实际使用 Claude 的结界。
5. 能与 GPT 突破教会守卫，先救出 Claude，再和她共同击败 D 教皇，看到两人自由生活的结局。
6. 进度能通过 Scala 后端写入 PostgreSQL；在同一浏览器刷新后，能通过“继续游戏”返回最近成功保存的检查点，恢复任务、伙伴和配置。
7. 普通倒下、GPT 试炼失败、存档加载或保存失败均有明确反馈，并能重试；两次剧情战败或重伤不造成流程卡死。

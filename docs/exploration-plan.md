# 非线性区域探索改造

依据 main 的 e6cb29f 剧本扩展。仅在 main 开发，不读取、合并或修改其他 agent 分支。

## 业务与页面边界

PlayerService 继续维护玩家、账号、会话与进度版本，AdventureService 继续维护 AdventureTable、GameSaveTable、ProgressOperationTable。探索不新增服务或网络逐帧调用。安全快照新增探索记录，地图、物品和事件仍是版本化内容；保存消息在原事务中验证探索条件和成长上限。

StartPage（/）建立身份、开始或继续；AccountPage（/account）管理账号；GamePage（/game）增加区域小地图、调查提示、探索记录与成长信息。交互、战斗、地图连接使用页面内纯函数；组件订阅私有 Zustand；Tailwind 负责 UI，Canvas 负责世界绘制。页面 → 原有 XxxMessage 请求类 → 同名消息 plan → Adventure / GameSave / Player 的公开 Table 方法，不改动请求归属。

## 目标区域图

- 长阶 → 后山雨林 → 青瓦市集；雨林的瀑布宝箱与樵夫营地为可选岔路。
- 市集 ↔ 枫叶古道 ↔ 港镇；古道 ↔ 琉璃矿洞、古亭驿站。Qwen 在茶摊交互后给出海路任务。
- 港镇货栈街 ↔ 废船坞 ↔ 旧货仓库；水闸、浮桥、木桶梯子、寄居蟹支线与船坞宝箱可调查。GLM 交手在仓库，完成后从港镇渡海。
- 西海岸 ↔ 断罪裂谷 ↔ 晶石林；裂谷 ↔ 干涸河床；救出 Gemini 后开放北境路线。
- 北境雪径 ↔ 冰封古殿、避风营地、龙巢；古殿升降冰台和冰封宝箱是可选路线。
- 龙巢 ↔ 雪线针叶林 ↔ 西陆前哨 → 教堂回廊；回廊 ↔ 左翼圣物厅、右翼图书馆、内庭；内庭 ↔ 主殿，最终逃离保持原剧情。

区域内使用多个方向的出口，分支之间允许来回走，长途渡海和最终逃离为明确的单向剧情边界。主线条件阻止跳过必要剧情，宝箱成长和支线战斗不是通关前提。已清理区域回访不重复战斗、剧情和奖励。

## 探索与成长

用稳定 ID 保存访问地图、看过的对话、打开的宝箱、机关与任务标记。成长从已收集物品推导，不接受客户端随意填伤害或上限。灵谷每份 HP +20 并回满 HP；润珠每份 MP +20，回复速度每份 +0.5/秒（剧本未定加速量，首轮采用此值）；硬鳞每份基础普攻 +15%；潮汐核心每份基础水球伤害及半径 +20%，同类加成累加。营地恢复资源和冷却，展示吃饭动作并形成检查点。

新增内容需覆盖 NPC 原文、路牌、可破坏荆棘、船坞水闸与木桶、冰台、陷阱预警、支线怪物、宝箱守卫、白皮书调查和生活支线。没有跳跃键，浮桥与升降平台通过近距离调查触发短距离跨越，保持俯视动作游戏输入一致。

## 存档与验证

移除“地图数组之前的全部关卡必须已完成”的假设，改用地图／事件前置条件、已完成遭遇、伙伴解锁与物品来源校验。旧版记录不删除；兼容迁移应在载入时完成，明确补齐旧版主线标记，不赠送未探索的宝物。新记录保留回访位置与独立地图完成状态。

分阶段：内容图与校验 → 探索状态和存档 → 交互与成长 → 世界绘制和小地图 → 双难度规则／数据库／真实输入探索验证。测试必须包含两种分支顺序、回访、机关开闭、重复领取、升级后保存重载和回档恢复，以及保留主线 Boss 和结局链。

## 剧本落地与稳定标识

新增剧本将北境探索称为 4-A、古龙战称为 4-B。已有存档的古龙遭遇 ID `4-A` 保持稳定，对应新剧本的战斗节点 4-B；雪径探索使用地图与机关 ID，不复用遭遇 ID。GLM 战由港镇迁到仓库，Gemini 救援增加一名机械督战官。序章 0-2 对白结束后直接落入雨林，不再要求在长阶自行寻找出口。

地图、机关和宝箱的坐标及依赖以 `content/world/exploration.json` 为准。长阶、渡海、龙巢离开和最终逃离承担剧情分段；同一探索区的岔路可返回。宝物与可选战斗不作为主线通关前提。原剧本的木箱跳跃与冰块跃台转为 F 调查跨越，不增加跳跃键；圣物厅的二选一奖励采用潮汐核心。上述是操作与内容落地选择，原对白仍按剧本保留。

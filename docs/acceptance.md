# 《断链之誓》验收记录

下述首版记录对应原线性版本，不能作为新增探索区域的完整通关证明。探索版验收单独记录在文末。

按企划 v0.5 第 8 节核对。完整试玩使用 Chromium 发送真实输入，只读状态选择行动。简单模式使用纯键盘，困难模式使用键鼠。两次从新冒险走到制作名单，均完成八个战斗节点，零重试，刷新后成功继续，浏览器错误列表为空。零重试描述本次操作结果。

| --- | --- |
| 1 序章 | 从标题页实际操作击退三名近卫，经历分离过场、集市对白，再进入林道。gameplay 浏览器用例另验过场暂停和跳过。 |
| 2 旅途 | 通关记录依次包含港镇追逐、GLM 投降、渡海、Gemini 救援、GPT 试炼与休整。harbor-chase 用例验证追逐后载入安全点。 |
| 3 主角技能 | 单测分别在 MP 不足与 CD 中施法，验证拒绝、资源和弹体。独立林道实战仅用摆尾清除三只晶石兽和两名术士，剩余 76 HP、100 MP。 |
| 4 三名援助 | 通关记录按 GLM、GPT、Claude 顺序解锁。六种有序双槽组合均保留各自 CD。两难度逐个释放三位伙伴，各生成一次施法效果，GPT 伤害相同，Claude 实际净化法阵的测试验证五秒反击窗口。 |
| 5 终章 | 两条实战均经过破穹顶、三波回廊、内庭呼唤和切磋、终战准备、教皇两阶段、坍塌、双 CG、小巷与名单。 |

| 8 对白 | 剧本提取、说话人映射和立绘对手选择有确定性检查。对白状态单独推进文字，战斗、MP、CD 与游戏时长冻结。浏览器用确认键完成对白后继续移动战斗。 |

| 11 输入 | 两套预设完成全流程。键盘使用方向键、Tab 锁定、J／K、Q／E 和菜单确认；键鼠使用光标瞄准与左右键。专项操作仅用键盘保存手动槽、把字号从 20 调到 21、读取该记录，读档后字号仍为 21。settings 和 keyboard 用例验证独立改键、冲突交换、提示和刷新。 |

| 13 动作 | 绘制按清单取帧及脚底锚点。四向行走每向四帧，摆尾三帧共 340ms。攻击结算、角色施法和区域特效分开，规则检查覆盖单次扣费、命中与连续帧不重复触发。 |

| 16 剧情重伤与终战重试 | trial-retry 定点构造龙巢破盾窗口，以实际输入触发获胜。重伤过场禁存、无失败菜单，治疗后仅提交一次已清场的 100 HP／100 MP 快照。终战检查点单独保留 Claude 与另一名伙伴，困难教皇失败后可从该检查点恢复。 |

## 复验

- 运行环境、完整检查与双难度操作脚本见[运行说明](running.md)。前端规则测试、真实数据库测试、浏览器专项与完整通关分别记录。
- 定点用例可设置合法存档或战斗前置条件。两条从头通关均通过正常 UI 启动和推进。林道仅用摆尾的检查从合法林道检查点开始。
- 观察范围为桌面 Chromium 和本机 PostgreSQL。WebAudio 验证测量实际信号；音色偏好由试玩者判断。原有素材和新增素材的出处见[素材清单](assets.md)。

完整检查通过 41 项前端单测、13 项 Scala 后端测试和 16 项浏览器测试。生产构建另外验证了标题页、新建、对白、暂停设置、手动保存和刷新继续。两条全程试玩使用 e50de7f 的战斗与剧情版本；随后 b008c54 的菜单焦点、难度显示和 HUD 调整通过完整检查和构建版复验。

## 账号、启动与操作修订

- 实际运行同一项目的 start、重复启动、status、stop 与运行中 restart。重新启动后 Scala 健康接口与游戏页均可访问。
- 游客新建冒险后注册，在独立浏览器上下文用同一账号继续。错误密码与重复用户名被拒绝，退出后旧令牌返回 401。
- 浏览器实测开始游戏进入原生全屏，Esc 打开帮助，能看到当前键位并进入更改页面。Canvas 绘制测试按实际输入核对每个方向的行走、摆尾和水球施法图集帧。
- 左、右 Control 均可快进。过场专项中，相近的 0.22 秒输入区间分别推进约 0.23 秒、1.75 秒和 0.22 秒，对应正常播放、按住 Control、松开。
- 本轮全套检查通过 41 项前端单测、14 项 Scala 测试及 18 项浏览器测试。生产构建另行通过账号注册、全屏进入、快进和帮助菜单检查。

## 自动索敌与出口修订复验

- GPT 援助按前方 90°、440 像素选择最近存活敌人；四方向单测验证范围伤害只结算一次、背后目标不受伤及无目标不消耗 CD。修复星落中心目标默认向下击退，中心目标现在沿远离主角的方向退开。
- 水球测试覆盖四方向施法前摇中横向移动，落点仍与出手选定点一致；弹体到终点时不超射。浏览器用真实方向键、E、K 验证四方向 GPT 与水球命中，并检查实际 Canvas 图像。星落图像使用素材地面锚点，避免特效位置与伤害位置错开。
- 所有普通房间的规则测试验证清场后步行穿过出口、未清场不能切图和出口外侧不能误触发。浏览器从实际存档恢复已清场林道，按 D 走入三格围墙口进入港镇，全程不按交互键。查看林道出口与长阶截图，确认蓝色箭头、围墙缺口及浅色长条移除。
- 本次前端单测 51 项、数据库测试 14 项及生产构建通过。浏览器全套 19 项中 18 项直接通过；旧 keyboard 用例未等待开场对白出现，修正等待条件后连续三次通过。绘制锚点调整后另复验四方向技能、出口及动作绘制专项。
- 生产静态服务器直接访问 /account、/account/、/game、/game/ 和 / 均返回 SPA。README 环境版本与本机及锁文件核对；Windows 手动迁移步骤尚未在 Windows 实机执行。此次未重复两条从头通关，以上关卡专项与首版完整通关证据分别记录。

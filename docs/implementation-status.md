## 已确定的实现边界

- 固定 60Hz 模拟，960×540 视口，32 像素地块；浏览器负责即时战斗，后端不模拟每帧。
- content 是共享版本化 JSON；前端构建读取，后端 sbt resourceGenerator 打包相同目录。
- 快照 stage：arrival（尚未完成进入对白）、ready（对白完成/战斗前）、cleared（本地图遭遇和结束对白已完成）、ending/finished（仅尾声）。战斗、连续过场不可保存。
- completed 精确包含此前地图遭遇，以及 cleared 时当前地图遭遇。
- GLM、GPT、Claude 分别在 harbor/lair/garden 的 cleared 状态解锁。此内容契约修改必须同时修改后端验证和游戏流程。
- 普通回档忠实恢复资源，检查点重试回满并重置遭遇/CD；两者不可混用。
- 暂存逻辑仍需纳入完整终章检查点实现：在 Claude 入队后、教皇开战前给出安全准备。
- 全部技能与动画解耦，以行动 ID/阶段边界只结算一次，不能通过绘制帧触发伤害。
- 两业务服务＋system 已确认；角色、敌人、地图不做无业务必要的独立微服务。

# 实施状态

《断链之誓》已接通从新冒险、十二张地图、八个战斗节点到尾声与刷新继续的主流程。运行入口和依赖见[运行说明](running.md)，每项企划要求对应的测试或试玩记录见[验收记录](acceptance.md)。

## 代码与内容

- 浏览器按固定 60Hz 处理输入、碰撞、敌人、弹体、伙伴援助与剧情。960×540 逻辑画布使用原人物图集、新生成的地形及敌人图集。十六段剧本场景、两处战中呼唤、八组过场及两张原 CG 构成主线。
- PlayerService 支持游客、保留游客存档的注册、跨浏览器登录和退出当前会话，AdventureService 管理冒险、存读档、内容校验与幂等。HTTP 身份解析与 PostgreSQL 事务位于服务入口，逐帧战斗在浏览器执行。
- 每次冒险具有五个手动槽和三条自动历史。安全快照记录难度、位置、任务、伙伴、资源及冷却。普通回档忠实恢复资源，检查点重试恢复满资源。尾声只接受可继续到结局的阶段。
- 当前内容版本为 1.1.0。载入不兼容的记录时返回明确错误。战斗或过场期间可以暂停和查看存档，写入仅在安全状态开放。
- 角色、地图、关卡和敌人的归属、两页面调用的请求与服务目录见[架构说明](architecture.md)。Git 跟踪源码、原始素材、生成记录与配置；开发数据库和身份令牌留在本机。

进入冒险时请求浏览器全屏，游戏视口保持画面比例。Esc 菜单中的帮助按当前绑定展示键鼠或纯键盘操作。主角行走按移动向量选帧，攻击按出手时的方向选帧。左右 Control 均支持按住快进对白与过场。
